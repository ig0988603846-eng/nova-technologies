NOVA TECHNOLOGIES — WEBSITE

START THE WEBSITE
1. Extract this ZIP file.
2. Keep index.html, css, js and assets together in the same folder.
3. Open index.html in a browser to preview the website.
4. To publish it online, upload the extracted website files to a hosting service such as Netlify.

CONTACT BUTTONS
- Email opens the visitor’s email app with nova.technologies.et@gmail.com pre-filled.
- Phone opens the device dialer using the Ethiopia international number +251988603846.
- Instagram, TikTok and Telegram are displayed as text only, as requested.

EDIT CONTACT DETAILS
Update js/config.js if the company contact details change.

PROJECT FILES
- index.html: website page
- css/style.css: responsive design and rounded contact cards
- js/config.js: contact details
- js/translations.js: language text
- js/main.js: navigation, theme, language and contact links
- assets/: NOVA logo files

NOTES
- The email link opens an email app; the website does not send email itself.
- The phone link opens the device dialer; the visitor chooses whether to place the call.
- Email and phone are the only clickable contact cards.


PWA / INSTALLABLE WEB APP
This version includes a web app manifest, app icons and a service worker.
After deploying the extracted files to Netlify over HTTPS, open the website in Chrome on Android and use the browser menu > Install app (or Add to Home screen).
The service worker caches the core website files for basic offline access after the first successful visit.
